# 心镜 - 基于多模态情感计算的 AI 心理陪伴助手

省级二等奖项目 | 后端开发

## 技术栈

- Python 3.9
- FastAPI + Uvicorn
- OpenCV / DeepFace / Whisper
- MySQL
- WSL2 / Ubuntu

## 功能模块

- 文本对话与情感分析
- 图像情绪识别（OpenCV + DeepFace）
- 语音转文本（Whisper）
- 情感报告与历史记录

## 项目结构

- api/：接口层
- services/：业务服务层
- models/：数据模型
- utils/：工具函数
- config.py：配置
- main.py：入口

## 快速启动

1. 安装依赖：pip install -r 代码/project/requirements.txt
2. 启动后端：python backend_api.py
3. 打开 index.html 使用前端界面
